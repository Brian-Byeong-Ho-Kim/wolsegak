개인정보처리방침

이티컴퍼니(이하 "회사")는 월세각(wolsegak.com) 이용자의 개인정보를 「개인정보 보호법」에 따라 처리하며, 다음과 같이 처리방침을 공개합니다.

1. 처리 목적

  • 회원 식별과 로그인 유지
  • 관심 지역, 비교한 매물 조건, 예산을 저장하고 여러 기기에서 이어서 보여 주기
  • 로그인 요청 남용 방지(요청 횟수 제한)
  • 문의 응대

2. 처리하는 개인정보 항목

구분항목수집 방법
카카오 로그인필수: 카카오 회원번호, 닉네임
선택: 카카오계정 이메일		이용자 동의 후 카카오에서 제공
이메일 로그인필수: 이메일 주소이용자가 직접 입력
서비스 이용 중 저장관심 지역, 비교한 매물 조건(지역·보증금·월세·면적·층·관리비 등 이용자가 입력한 값), 예산이용자가 저장·비교할 때
자동 생성로그인 유지 정보(쿠키), 로그인 링크 요청 시 IP 주소로그인할 때

회원이 아니어도 날짜별 방문 수와 「매물 비교」 횟수를 셉니다. 이때는 쿠키를 쓰지 않고, 개인을 알아볼 수 있는 정보를 저장하지 않습니다. 비회원이 입력한 보증금·월세 등은 이용자의 브라우저 안에서만 계산하고 회사로 보내지 않습니다.

3. 보유 및 이용 기간

  • 회원 정보와 저장한 내용: 회원 탈퇴 시 바로 파기합니다. 「내 정보 → 회원 탈퇴」로 직접 탈퇴할 수 있습니다.
  • 로그인 유지 정보: 마지막 로그인부터 30일. 로그아웃하면 바로 삭제합니다.
  • 이메일 로그인 링크와 요청 IP 주소: 링크는 15분 동안 한 번만 쓸 수 있고, 기록은 만료 후 1일 안에 삭제합니다.

4. 제3자 제공

회사는 이용자의 개인정보를 제3자에게 제공하지 않습니다. 법령에 따른 요청이 있는 경우는 예외로 합니다.

6. 파기 절차와 방법

보유 기간이 끝나거나 탈퇴하면 데이터베이스에서 바로 삭제합니다. 종이 문서로는 개인정보를 보관하지 않습니다.

7. 이용자의 권리와 행사 방법

이용자는 언제든지 개인정보 열람, 정정, 삭제, 처리 정지를 요구할 수 있습니다. 「내 정보」에서 직접 탈퇴하거나 아래 보호책임자에게 요청하면 지체 없이 처리합니다.

8. 안전성 확보 조치

  • 모든 통신은 HTTPS로 암호화합니다.
  • 비밀번호를 받지 않습니다(이메일은 일회용 링크).
  • 로그인 유지 정보와 로그인 링크는 원래 값이 아닌 해시값으로만 저장합니다.
  • 카카오 접근 토큰은 로그인 확인에만 쓰고 저장하지 않습니다.
  • 개인정보에 접근할 수 있는 사람을 운영자로 한정합니다.

9. 쿠키와 브라우저 저장소

  • wsg_sid: 로그인 유지에 필요한 쿠키입니다. 마지막 로그인부터 30일 동안 유지되며, 로그아웃하면 바로 삭제됩니다. 막으면 로그인을 쓸 수 없습니다.
  • 관심 지역, 비교 목록, 예산, 방문 집계용 날짜 표시는 이용자 브라우저의 저장소(localStorage)에 저장합니다. 브라우저 설정에서 언제든 지울 수 있습니다.
  • 광고나 행태 추적용 쿠키는 쓰지 않습니다.
  • 지도와 위치 검색에는 OpenStreetMap과 Nominatim(OpenStreetMap 재단)을 씁니다. 이때 이용자의 브라우저가 해당 서비스에 직접 접속하므로 IP 주소와 검색어가 전달될 수 있습니다.
